# Исправления фронтенда

## Что исправлено

1. **Пункты снова открываются по нажатию**
   - `App.css` теперь реально подключён в `App.tsx`.
   - Маркеры пунктов имеют явные `pointer-events`, `touch-action` и обработку `pointerdown/click` без передачи жеста карте.
   - Маркеры метро и маршрута не перехватывают нажатия по пунктам.

2. **Маршрут остаётся на той же карте**
   - Убран старый сценарий с длинным белым списком станций поверх карты.
   - Маршрут рисуется по `route.segments`, каждый участок цветом своей линии.
   - Пересадки рисуются отдельными пунктирными переходами.
   - Добавлен белый halo для читаемости маршрута на OSM.
   - После построения карта автоматически делает `fitBounds` по маршруту.
   - Для маршрута из одной станции карта корректно приближается к этой станции.

3. **Мобильная карточка работает как bottom sheet**
   - Карточку можно опустить свайпом вниз за серую ручку.
   - Свайп вверх возвращает карточку.
   - После нажатия «Показать маршрут на карте» карточка автоматически опускается, освобождая карту.

4. **Контакты и бронирования берутся из `/api/places`**
   - `manager_info` и `booking` больше не теряются в `useHostels`.
   - Показываются имя и телефон менеджера.
   - Показываются статус, дата и ID бронирования текущего пользователя.
   - После успешной брони `/api/places` перечитывается автоматически, поэтому данные и количество мест обновляются без перезагрузки страницы.

5. **Тестовые точки вне Москвы**
   - Для пунктов/пользователя дальше 20 км от ближайшей станции Московского метро не строится бессмысленный маршрут через Москву.

6. **Карта метро**
   - Отрисовываются также ветвления (`branches`).
   - МЦК отображается двойной линией.
   - Выбранный маршрут больше не рисуется одной синей ломаной.

## После распаковки

Если ранее была ошибка `rolldown ... ERR_MODULE_NOT_FOUND`, рекомендуется один раз пересобрать зависимости:

```bash
rm -rf node_modules
npm cache verify
npm ci
npm run build
```

Если `npm ci` сообщает о рассинхронизации `package-lock.json` и `package.json`:

```bash
rm -rf node_modules package-lock.json
npm install
npm run build
```

## Desktop/fullscreen bottom sheet

Обновлено управление карточкой пункта:
- после построения маршрута карточка автоматически сворачивается не только на телефоне, но и на desktop/fullscreen;
- на desktop остаётся компактная верхняя полоска с drag-handle;
- drag-handle поддерживает Pointer Events, поэтому карточку можно вытягивать вверх и опускать вниз мышкой;
- на мобильных сохранено прежнее поведение со свайпом;
- при открытии «Контакты и бронь» карточка автоматически разворачивается.

## v3: разворачивание карточки кликом

- Когда bottom-sheet опущен, клик/тап по его видимой верхней части сразу поднимает карточку наверх.
- Клик по самой ручке также поднимает карточку без перетягивания.
- Drag мышью и свайп пальцем сохранены.
- После реального перетягивания вниз browser click подавляется, поэтому карточка не раскрывается обратно сама.

## v4 — раскрытие свернутой карточки по клику
- Для свернутой карточки добавлена отдельная hit-area поверх всей видимой верхней части.
- На desktop зона имеет высоту 72 px, на mobile — 124 px.
- Обычный клик/тап по этой области разворачивает карточку.
- Та же область поддерживает drag мышью и свайп пальцем.
- Крестик закрытия поднят над hit-area и продолжает работать независимо.

## v5 — MAX expanded/fullscreen bottom sheet
- Убран `Pointer Events + setPointerCapture` для drag карточки: MAX Desktop WebView может обрабатывать его нестабильно.
- Добавлены отдельные mouse и touch события.
- Движение мыши отслеживается на `window`, поэтому drag не обрывается за пределами ручки.
- Короткий клик/тап по верхней ручке теперь переключает карточку в обе стороны: раскрытая сворачивается, свернутая раскрывается.
- После построения маршрута сворачивание выполняется после двух `requestAnimationFrame`, чтобы MAX WebView успел пересчитать высоту карточки.
- Верхняя зона ручки увеличена до 42px.

## v6: универсальная bottom-sheet карточка
- Автоматическое сворачивание больше не измеряет `offsetHeight` и не ждёт `requestAnimationFrame`.
- Свернутое положение задаётся CSS: `translateY(calc(100% - var(--hostel-sheet-peek)))`.
- Поэтому положение одинаково работает при любом размере/масштабе, в браузере, MAX Web/Desktop и мобильном WebView.
- Короткое нажатие по ручке переключает карточку непосредственно на `mouseup/touchend`, даже если MAX подавляет событие `click`.
- Drag мышью и пальцем отслеживается на `window`, поэтому не обрывается при выходе за ручку.
- После «Показать маршрут» карточка сворачивается сразу через boolean-state без измерения DOM.
