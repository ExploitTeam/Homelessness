# Исправления фронтенда

## Что исправлено

1. **Пункты снова открываются по нажатию**
   - `App.css` теперь реально подключён в `App.tsx`.
   - Маркеры пунктов имеют явные `pointer-events`, `touch-action` и обработку `pointerdown/click` без передачи жеста карте.
   - Маркеры метро и маршрута не перехватывают нажатия по пунктам.

2. **Маршрут остаётся на той же карте**
   - Убран старый сценарий с длинным белым списком станций поверх карты.
   - Маршрут рисуется по `route.segments`, каждый участок цветом своей линии.
   - Пересадки рисуются отдельными пунктирными переходами.
   - Добавлен белый halo для читаемости маршрута на OSM.
   - После построения карта автоматически делает `fitBounds` по маршруту.
   - Для маршрута из одной станции карта корректно приближается к этой станции.

3. **Мобильная карточка работает как bottom sheet**
   - Карточку можно опустить свайпом вниз за серую ручку.
   - Свайп вверх возвращает карточку.
   - После нажатия «Показать маршрут на карте» карточка автоматически опускается, освобождая карту.

4. **Контакты и бронирования берутся из `/api/places`**
   - `manager_info` и `booking` больше не теряются в `useHostels`.
   - Показываются имя и телефон менеджера.
   - Показываются статус, дата и ID бронирования текущего пользователя.
   - После успешной брони `/api/places` перечитывается автоматически, поэтому данные и количество мест обновляются без перезагрузки страницы.

5. **Тестовые точки вне Москвы**
   - Для пунктов/пользователя дальше 20 км от ближайшей станции Московского метро не строится бессмысленный маршрут через Москву.

6. **Карта метро**
   - Отрисовываются также ветвления (`branches`).
   - МЦК отображается двойной линией.
   - Выбранный маршрут больше не рисуется одной синей ломаной.

## После распаковки

Если ранее была ошибка `rolldown ... ERR_MODULE_NOT_FOUND`, рекомендуется один раз пересобрать зависимости:

```bash
rm -rf node_modules
npm cache verify
npm ci
npm run build
```

Если `npm ci` сообщает о рассинхронизации `package-lock.json` и `package.json`:

```bash
rm -rf node_modules package-lock.json
npm install
npm run build
```

## Проверки

- Все TS/TSX файлы прошли синтаксическую проверку TypeScript.
- Внутренние типы проекта проверены с `noUnusedLocals` / `noUnusedParameters`.
- Маршрутизатор отдельно прогнан на нескольких маршрутах с пересадками.
