# MAX Mini App — карта пунктов помощи

Отображает данные из `GET /api/places`: пункт, категорию, фонд и его описание, всех контактных лиц, график, свободные места и собственную бронь пользователя.

В карточке пункта кнопки **«Контакты»** и **«Забронировать»** закреплены снизу. Переход к контактам не скрывает остальную информацию.

## Сборка

Основной способ: `npm ci && npm run build`.

Если установленным пакетам Vite недоступна нативная библиотека в текущей среде: `npm run build:portable`. Альтернативная сборка включает собственные копии React, ReactDOM и MapLibre в `dist/vendor`. Требует установленного каталога `node_modules`.

В корневом архиве проекта уже находится готовая сборка `Web/dist`, дополнительно собирать ничего не нужно.
