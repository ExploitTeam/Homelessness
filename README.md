# Хакатон по разработке бота для Макс.
## 1. Назначение решения. 
### Мы разработали бота, который **поможет** людям найти и получить помощь в трудной жизненной ситуации.<br>
За основу мы взяли благотворительный фонд **"Ночлежка"**, который предоставляет
бесплатные места для ночевки, обогрева в холодное время года, бесплатные
медикаменты и еду, а так же многое другое. <br>
При помощи созданного бота
пользователи могут найти **ближайшую** точку, посмотреть доступные места,
забронировать себе место и связаться с менеджером. **Для администраторов 
и менеджеров выдаюься дополнительные права**, позволяющие создавать и 
редактировать пункты, принимать или отклонять бронь, редактировать пользователей.

## 2. Основной пользовательский сценарий
- Пользователю следует указать свой номер в главном меню, чтобы с ним мог связаться
менеджер
- Нажав на кнопку "Отправить геопозицию" пользователь сможет ознакомиться с 
ближайшими пунктами к нему, включить фильтры типов пункта и ознакомиться
