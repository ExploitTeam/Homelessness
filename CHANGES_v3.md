# Изменения v3 — навигация, геолокация и даты

Эта версия продолжает v2 и сохраняет структуру БД, API и сайт мини-приложения.

## 1. Новая навигация управления пунктами

Для **администратора бота** и **администратора фонда** путь:

`Главное меню → 🏛️ Фонды → выбранный фонд → 🏠 Управление пунктами → выбранный пункт`.

Внутри фонда можно создать новый пункт (при наличии прав) и редактировать существующие. Из списка пунктов кнопка «К фонду» возвращает в карточку выбранного фонда. У администраторов отдельной кнопки «Управление пунктами» на главной больше нет. Нажатия по сохранённым старым кнопкам `edit_homestay` ведут в меню фондов.

Для **менеджеров** кнопка `🏠 Управление пунктами` по-прежнему доступна из главного меню. Они видят только свои назначенные пункты, не могут создавать пункты или управлять фондом.

Права повторно проверяются в обработчике каждой кнопки; администратор одного фонда не получит доступ к пунктам другого по вручную составленному callback.

## 2. Главная без дублирования истории

С главной удалена кнопка «История моих броней». История доступна внутри `📋 Мои бронирования → 🕘 История всех моих броней`.

## 3. Удобный текст ближайших пунктов

При отправке геолокации и изменении фильтра/страницы сообщения содержат Markdown-заголовки, отступы, эмодзи и отдельную визуально заметную строку `🏛️ Фонд`. Между карточками добавлена пустая строка (двойной перевод строки `\n\n`). Порядок расстояний не изменён — пункты **не** группируются по фондам, чтобы не нарушать сортировку от ближайшего к дальнему.

## 4. Читаемые даты

В сообщениях о брони, истории, уведомлениях и профиле дата отображается, например, как `19.10.2026 в 17:08` вместо `2026-10-19T17:08:20`. Внутри SQLite и API даты остались в ISO 8601 для сохранения совместимости; отображение не переводит время в другой часовой пояс.

## Обновление

1. Остановите бота, сохраните копии рабочей базы `.db` и `.env`.
2. Замените файлы из архива, оставив существующие `.db` и `.env` на сервере.
3. Перезапустите контейнер/бота (`docker compose up -d --build`).
4. Проверьте под администратором навигацию `Фонды → Фонд → Управление пунктами` и отправьте геолокацию обычным аккаунтом.

Никакие миграции БД для конкретно этих четырёх правок не нужны.

## Автоматические проверки

```bash
python -m unittest discover -s tests -v
python -m compileall -q main.py database maxbot
```

Интеграционную проверку отображения кнопок в настоящем клиенте MAX нужно выполнить с действующим токеном.
